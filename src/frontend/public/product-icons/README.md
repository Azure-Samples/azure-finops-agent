# Product icons

Official product icons, unmodified, that the start page shows under its title and beside each question to name the
products its answers cover:

| File | Product | Source and terms |
| --- | --- | --- |
| `azure.svg` | Azure | [Azure architecture icons](https://learn.microsoft.com/azure/architecture/icons/) V25 (November 2026), `10018-icon-service-Azure-A.svg`, under Microsoft's icon terms |
| `foundry.svg` | Microsoft Foundry | [Azure architecture icons](https://learn.microsoft.com/azure/architecture/icons/) V25, `035746832-icon-service-AI-Foundry.svg`, under Microsoft's icon terms |
| `agent-365.svg` | Microsoft Agent 365 | [Microsoft Power Platform icons](https://learn.microsoft.com/power-platform/guidance/icons) (December 2025), `Agent365_scalable.svg`, under Microsoft's icon terms |
| `copilot.svg` | Microsoft 365 Copilot | The Microsoft 365 product icons Fluent UI serves for apps that connect to Microsoft 365, `brand-icons/product/svg/copilot_48x1.svg` on Microsoft's Fluent CDN (`res-1.cdn.office.net`, `fabric-cdn-prod_20251008.001`), under the [Fluent UI assets license](https://aka.ms/fluentui-assets-license) |
| `github.svg` | GitHub | [Primer Octicons](https://github.com/primer/octicons) `mark-github-24.svg`, MIT license, © GitHub Inc., used to refer to GitHub as its [logo guidelines](https://github.com/logos) allow |

None of these icons is covered by this repository's MIT license, and each owner keeps all other rights.

- Microsoft's icon terms allow its product icons to illustrate how Microsoft products work together, with the product
  name near the icon, and forbid cropping, flipping, rotating, distorting them or using them for another product.
- The Fluent UI assets license allows Microsoft 365 product icons in an app that uses a Microsoft API to work with a
  Microsoft service, to show that it integrates with that product: unaltered, never as a logo or in a sentence, never
  more prominent than the app's own name, and in a lineup with the full product name beside the icon.

The start page shows each icon with its full product name: under the title as a lineup labelled "Works with", and as each
card icon's tooltip.
